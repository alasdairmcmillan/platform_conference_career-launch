# Associations page content — do not hand-edit

Everything in this directory (except this README) is synced automatically from
the `associations/` folder of
https://github.com/gilpages/career-launch-industry-partner by
`.github/workflows/sync-partners.yml`. Any manual edits here will be
overwritten on the next sync.

To change the associations page, update the source repository. The page is
served at `/associations` via a rewrite in `next.config.ts`.
